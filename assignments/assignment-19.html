Assignment 19: CSS Grid Layout Systems

Explore two-dimensional layout architecture using CSS Grid. Learn track definitions with fraction units (fr), fluid auto-responsive grids with auto-fit and minmax(), and named layout areas with grid-template-areas.

1. Basic Grid & Fractional Tracks (repeat(3, 1fr))

The fr unit represents a fraction of the available free space within the grid container. Using repeat(count, track) allows compact track definitions.

2. Fluid Responsive Grid without Media Queries

By combining repeat(auto-fit, minmax(200px, 1fr)) with gap, the grid automatically calculates the optimal column count based on available container width, wrapping cards automatically without any @media breakpoints.

3. Named Grid Template Areas

The grid-template-areas property allows developers to visually diagram layout regions using named strings. Elements are subsequently mapped into regions via grid-area: name.

area: main

This central region houses the principal coursework content. Using named template areas, this section automatically realigns when swapping layout templates.

Page Footer (area: footer) • Web Development Learning Hub 
.page-layout {
  display: grid;
  grid-template-columns: 220px 1fr;
  grid-template-rows: auto 1fr auto;
  grid-template-areas:
    "header header"
    "sidebar main"
    "footer footer";
  gap: 0.75rem;
}

.site-header { grid-area: header; }
.site-sidebar { grid-area: sidebar; }
.main-content { grid-area: main; }
.site-footer  { grid-area: footer; }
