Assignment 2: Quotations, Citations & Computer Code

Explore semantic quotations, source citations, abbreviations, keyboard input tags, and preformatted computer code blocks.

1. Long Quotations with Blockquote & Cite

The <blockquote> element represents an extended quotation from external material, coupled with a cite attribute and a <cite> tag citing the speaker.

“The Web as I envisaged it, we have not seen it yet. The future is still so much bigger than the past.”
— Tim Berners-Lee, Inventor of the World Wide Web

2. Inline Quotations & Abbreviations

During the early development of the Web, Tim Berners-Lee famously asserted that the power of the Web is in its universality. Access by everyone regardless of disability is an essential aspect.

Technical specifications for the open web platform are developed and published by the W3C, which maintains standards for HTML, CSS, and web accessibility.

3. Computer Code Formatting

HTML provides structural tags to convey keyboard commands, inline programmatic terms, preformatted blocks, and computer terminal output.

Keyboard Keys (<kbd>)

To open developer tools in most web browsers, press Ctrl + Shift + I on Windows or Linux.

Inline Code (<code>)

Use the <blockquote> element for block quotes and the cite attribute to link the quote origin.

Preformatted Block Code (<pre> & <code>)

<!-- Example of Semantic Quotations -->
<blockquote cite="https://www.w3.org/">
    Universal access is the foundation of the Web.
    <footer>— <cite>Tim Berners-Lee</cite></footer>
</blockquote>

Terminal Output (<samp>)
