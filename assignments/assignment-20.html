Assignment 20: CSS Transitions & Keyframe Animations

Explore CSS transitions between state changes, compare timing curves with an interactive race track, and build continuous looping animations using @keyframes.

1. State Transitions (transition: property duration timing-function)

CSS transitions allow values to change smoothly over a specified duration rather than snapping instantaneously. Hover your cursor over both cards below to see the visual contrast:

With Smooth Transition

transition: transform 0.3s ease, box-shadow 0.3s ease;

• Fluid Elevation & Glow

Without Transition (Abrupt)

transition: none; (Instant jump)

• Jarring Instant Shift 
.smooth-card {
  transition: transform 0.3s ease, box-shadow 0.3s ease, border-color 0.3s ease;
}

.smooth-card:hover {
  transform: translateY(-8px);
  box-shadow: 0 12px 24px rgba(37, 99, 235, 0.15);
}

2. Timing Functions & Easing Curves Race

Timing functions dictate how acceleration occurs over time. All runners below share the exact same duration (2.2 seconds), but reach milestones differently based on their easing curve:

Status: Active loop running
linear Steady constant velocity
→
ease Default: slow start, quick, slow finish
→
ease-in Starts slow and accelerates steadily
→
ease-out Fast start, decelerates gently at the end
→
ease-in-out Slow start and slow finish, fast middle
→

3. Continuous Loop Animations (@keyframes)

@keyframes allows multi-stage continuous animations that do not rely on user interaction triggers:

@keyframes pulseBeacon {
  0%   { transform: scale(0.6); opacity: 0.9; }
  100% { transform: scale(2.0); opacity: 0.0; }
}

@keyframes spinLoader {
  0%   { transform: rotate(0deg); }
  100% { transform: rotate(360deg); }
}

@keyframes shimmerGradient {
  0%   { background-position: 200% 0; }
  100% { background-position: -200% 0; }
}
