Assignment 17: CSS Box Model & Sizing

Explore the four foundational concentric layers of every rendered HTML element, compare content-box versus border-box calculations, and discover how vertical margin collapse functions in document flow.

1. The Four Box Model Layers

Every HTML element generates a rectangular box comprised of four nested layers: Margin (outer spacing), Border (boundary line), Padding (inner clearance), and Content (inner text/media).

2. Sizing Comparison: content-box vs border-box

By default, CSS applies box-sizing: content-box, where declared width applies strictly to content, pushing padding and borders outward. In contrast, box-sizing: border-box absorbs padding and borders inside the declared width.

box-sizing: content-box (Browser Default)

Declared width is 240px. Padding and border expand the element outward.

Rendered Width: 308px
Declared Width: 240px
Padding (L+R): 48px
Border (L+R): 20px
Total Rendered Width = 308px

box-sizing: border-box (Modern Standard)

Declared width is 240px. Padding and border are absorbed inside the box.

Rendered Width: 240px
Declared Width: 240px (Locked)
Padding (L+R): 48px
Border (L+R): 20px
Inner Content Width = 172px

3. Interactive Margin Collapse Demonstration

When the vertical margins of two adjacent sibling block elements touch in normal flow, they combine (collapse) into a single margin equal to the largest of the two, rather than being added together.
