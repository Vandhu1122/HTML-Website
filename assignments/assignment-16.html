Assignment 16: Semantic Metadata & Machine-Readable Data

Structure content for search engines, calendar tools, and automated accessibility parsers.

1. Machine-Readable Dates & Times (<time>)

The <time> element translates human dates into standardized ISO-8601 timestamps:

  • Project Launch Date: October 5, 2026
  • Weekly Lab Session: Every Friday at 2:30 PM IST
  • Assignment Submission Deadline: October 15, 2026

2. Author & Contact Landmark (<address>)

The <address> element provides contact information for the author of a document or article:

Coursework Author: Vandana

Repository: HTML-Website on GitHub

Inquiries: contact@example.com

3. Machine-Readable Value Mapping (<data>)

The <data> element pairs human-facing text with a machine-readable value:

  • Course Catalog ID: Introductory Web Development
  • Course Module Level: Intermediate Markup Architecture
