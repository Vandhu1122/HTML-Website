What is the difference between inline and block elements?

Block elements (such as <div>, <p>, and <h1>) start on a new line and stretch across the full available width. Inline elements (such as <span>, <strong>, and <a>) only take up as much width as their content.

Why are semantic landmarks important for accessibility?

Landmark tags like <header>, <nav>, <main>, and <footer> provide clear page navigation points for screen readers, allowing users with visual impairments to jump directly to key content sections.

How does the native <dialog> element handle keyboard navigation?

When opened with showModal(), the browser traps keyboard focus within the dialog, disables interaction with the background content, and automatically dismisses the dialog when the Esc key is pressed.
