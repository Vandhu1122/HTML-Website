HTML5 Element Reference Index

A practical lookup guide cataloging essential HTML5 elements, semantic landmarks, input controls, tabular structures, and multimedia tags.

1. Document Architecture & Landmarks

Structural elements that establish page landmarks and convey meaningful document hierarchy to browsers and assistive technologies.

Element Description Landmark / Category Syntax Example
<header> Introductory container for introductory content, page headers, or navigational aids. Landmark (banner) <header><h1>Site Title</h1></header>
<nav> Section containing major navigational links for site or page traversal. Landmark (navigation) <nav><a href="/">Home</a></nav>
<main> Container for the dominant, central content unique to the individual document. Landmark (main) <main><article>...</article></main>
<section> Generic standalone thematic grouping of content, typically introduced by a heading. Sectioning Container <section><h2>Overview</h2></section>
<article> Self-contained, independently distributable composition (e.g., blog post, news story). Sectioning Container <article><h2>Article Title</h2></article>
<aside> Complementary section with content tangentially related to surrounding material (e.g., sidebars). Landmark (complementary) <aside><h3>Related Links</h3></aside>
<footer> Concluding container for nearest ancestor section or document containing copyright, author, or contact info. Landmark (contentinfo) <footer><p>&copy; 2026</p></footer>

2. Text Semantics & Formatting

Inline and block phrasing tags that communicate textual importance, quotations, code references, and keyboard keys.

Element Description Semantic Purpose Syntax Example
<strong> Indicates strong importance, seriousness, or urgency for its contents. Importance / Urgency <strong>Warning:</strong>
<em> Indicates stress emphasis that alters sentence interpretation and voice pitch. Stress Emphasis <em>Must</em> complete
<mark> Represents text highlighted or marked for reference or search relevance. Reference Highlighting <mark>search keyword</mark>
<blockquote> Indicates an extended section of quoted text from an external source. Block Quotation <blockquote cite="...">...</blockquote>
<q> Short inline quotation that browsers enclose in quotation marks. Inline Quotation <q>Web for all</q>
<abbr> Represents an abbreviation or acronym; full expansion provided via title attribute. Abbreviation <abbr title="HyperText Markup Language">HTML</abbr>
<code> Displays a short fragment of computer source code using a monospaced font. Inline Code Fragment <code>const total = 100;</code>
<kbd> Denotes user keyboard input, keystroke sequences, or voice commands. User Keystroke / Input <kbd>Ctrl</kbd> + <kbd>S</kbd>
<samp> Represents sample or quoted output from a computer program or system script. Program / System Output <samp>Success: 200 OK</samp>

3. Lists & Tables

Elements designed to organize sequential lists, unordered groups, definitions, and two-dimensional data grids.

Element Description Type / Role Syntax Example
<ul> Unordered list of items where order has no explicit sequence, rendered with bullets. Unordered List Container <ul><li>Item 1</li></ul>
<ol> Ordered list of numerical or alphabetical items where order represents a sequence. Ordered List Container <ol><li>Step 1</li></ol>
<dl> Description list enclosing term (<dt>) and description (<dd>) pairings. Description List Container <dl><dt>Term</dt><dd>Def</dd></dl>
<table> Tabular data container presenting multidimensional data in rows and columns. Table Root Container <table>...</table>
<thead> Encapsulates header rows defining the titles and scope of table columns. Table Header Group <thead><tr><th>Col</th></tr></thead>
<tbody> Encapsulates the set of table rows comprising the primary body data. Table Body Group <tbody><tr><td>Val</td></tr></tbody>
<tr> Defines a horizontal row of cells within a table header, body, or footer. Table Row <tr><td>Row cell</td></tr>
<th> Header cell providing title and semantic scope (col or row) for cells. Table Header Cell <th scope="col">Column 1</th>
<td> Standard data cell containing tabular values, text, or elements. Table Data Cell <td>Data Point</td>

4. Forms & Interactive Inputs

Controls for capturing user inputs, choices, text submissions, validation states, and gauge measurements.

Element Description Input Model / Role Syntax Example
<input> Interactive input field supporting various types (text, email, password, radio, etc.). Interactive Form Input <input type="email" name="user_email" required>
<select> Dropdown control providing a list of selectable <option> choices. Selection Menu <select><option>Option 1</option></select>
<textarea> Multi-line plain text editing control for messages, descriptions, and comments. Multi-line Text Field <textarea rows="4" cols="50"></textarea>
<datalist> Predefined set of recommended options providing autocomplete suggestions to an input. Autocomplete Option Source <datalist id="browsers"><option value="Chrome"></datalist>
<progress> Visual progress bar displaying the completion percentage of a task or upload. Task Completion Indicator <progress value="70" max="100">70%</progress>
<meter> Scalar measurement gauge within a known fractional range (e.g., disk usage, battery). Scalar Range Gauge <meter min="0" max="100" value="85">85%</meter>
<fieldset> Group container that clusters logically related controls and labels together. Control Group Container <fieldset><legend>Account</legend>...</fieldset>
<legend> Caption or heading representing the purpose of its parent <fieldset>. Fieldset Caption <legend>Contact Information</legend>

5. Multimedia & Graphics

Tags for embedding raster and vector graphics, audio tracks, video streams, canvas drawing, and nested browsing contexts.

Element Description Content Media Type Syntax Example
<img> Embeds an image into the document with accessible alternative text. Embedded Raster / Vector Image <img src="hero.webp" alt="Landscape illustration">
<picture> Responsive wrapper offering multiple image sources for art direction and device resolution. Responsive Image Switcher <picture><source srcset="wide.webp"><img src="std.jpg" alt=""></picture>
<audio> Embeds sound content such as music or audio streams with native playback controls. Embedded Audio Stream <audio controls src="audio.mp3"></audio>
<video> Embeds a video player with controls, captions, poster frame, and fallback sources. Embedded Video Stream <video controls poster="thumb.jpg" src="movie.mp4"></video>
<svg> Inline Scalable Vector Graphics container rendering scalable mathematical paths and shapes. XML Vector Graphics <svg viewBox="0 0 24 24" width="24" height="24">...</svg>
<canvas> Bitmap canvas surface supporting dynamic, scriptable 2D or 3D graphics rendering via JavaScript. Scriptable Graphics Surface <canvas width="400" height="200"></canvas>
<iframe> Nested browsing context embedding an external document, interactive map, or video player. Embedded Browsing Context <iframe src="https://example.com" title="External resource"></iframe>
